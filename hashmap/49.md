# 49. Group Anagrams

A ideia é agrupar as strings que são anagramas.

Ao invés de ordenar string por string e depois validar entre si, o que daria um tempo de `O(m * n log n)`, podemos considerar que a chave do hashmap de resultados será a contagem de letras da string, sendo um array de 26 posições (de `a` a `z`) e pra cada string que bater essa contagem, adicionamos ao array da resposta.

Pra transformar a letra em índice, usei `ord(char) - ord('a')`, o que transforma o intervalo de `a...z` em `0...25`.

Na versão ótima, o tempo de execução fica `O(m * n)`.
