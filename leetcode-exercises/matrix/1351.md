# 1351. Count negative numbers in a sorted matrix

O pensamento da resolução ótima é que a matriz tá ordenada de forma decrescente tanto em linha quanto em coluna.

Com isso podemos usar o método "escada" pra contar quantos números negativos tem nessa matriz.

Começando da última linha na primeira posição, sabemos que subindo o número aumenta e indo pra direita o número diminui.
